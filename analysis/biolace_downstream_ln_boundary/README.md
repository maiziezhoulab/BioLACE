Downstream analysis for human lymph node cell-type clustering.

The data comes from the Open-ST paper:

**Open-ST: High-resolution spatial transcriptomics in 3D**  
https://www.cell.com/cell/fulltext/S0092-8674(24)00636-6

## `boundary_analysis_human_ln.py`.
### example command: python boundary_analysis_human_ln.py   --h5ad /maiziezhou_lab/Datasets/ST_datasets/humanMetastaticLymphNode/GSE251926_metastatic_lymph_node_3d.h5ad   --backed   --section-col n_section   --section-id 19   --cluster-path /home/qinh3/biolace_downstream/biolace_ln_slice19_leiden_similarity   --tumor-clusters 1   --distance-window-min -200   --distance-window-max 2000   --outdir ./human_ln_boundary

1. "boundary": the distance between the cell and the tumor cluster boundary (negative means inside the tumor, positive means outside the tumor)
2. "modules score": we align biological functions with specific markers specified in the paper using z-score, the process is as follows.
    1. Find which marker genes are present in the h5ad file.
    2. Extract expression for those genes.
    3. Apply log1p transform to the expression values.
    4. Z-score each gene across cells.
    5. Average the z-scored expression values across the genes in that module.
3. "boundary curve" shows module score as a function of the boundary distance, expect the biological function indicator within the tumor cluster matches what is expected of the tumor
4. spatial_module_maps plot out the tissue, uses a red dotted line to circle the cluster(s) that are specified by your command to be tumor and plot out the module score for the spots within the tissue (it should be the same as the boundary curve, bust just visualized in tissue)

Important notes for usage:
1. tumor cluster selection: inspect the cluster generated by your algorithm, and pick one or multiple clusters that most closely resemble the tumor for the analysis (in the example BioLACE results directory, the tumor cluster is BioLACE cluster "1")
2. the markers are "inspired" by the paper -- I have commented out the original marker genes thare are mentioned in the original paper; and just for better visualization, I asked chatGPT to generate more markers for these functions for more robustness (the paper also mentioned hypoxia but did not give too much explanation, so I asked chatGPT to retreive which makrers have connection to that function)
3. the window for the distance can be automatically chosen, or specified. tune it based on your data
